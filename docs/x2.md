# Optional X2 decoding

0.7.0 supports `--x2` / `x2=True` with VSA or SOL. The
[MiniMax H3 X2 Detail VAE](https://huggingface.co/speach1sdef178/MiniMax-H3-X2-Detail-VAE)
doubles decoded width and height while retaining four-step sampling and generated
audio. X2 is off by default.

Both modes require **Python 3.11 and `[VSA]` dependencies** for the MLX decoder.
SOL + X2 uses SOL generation models and its matching native engine; it needs no
VSA model bundle. See [installation and SOL migration](install.md).

## Sampling and output

| Sampling | Landscape canvas | Landscape output | Portrait output |
| --- | --- | --- | --- |
| 544p | 960 × 544 | 1920 × 1088 | 1088 × 1920 |
| 576p | 1024 × 576 | 2048 × 1152 | 1152 × 2048 |

Portrait swaps the sampling dimensions. Reference budgets follow the sampling
canvas. All decoded pixels are retained: 544p + X2 delivers 1088, not 1080, on
the short edge. 544p requires X2. **768p + X2 is rejected**; ordinary 768p remains
available.

```sh
h3 generate --image landscape.jpg --prompt-file scene.txt --duration 5 \
  --resolution 544p --x2 --output landscape-x2.mp4
h3 generate --mode SOL --image portrait.jpg --prompt-file scene.txt --duration 5 \
  --resolution 544p --x2 --aspect-ratio 9:16 --output portrait-sol-x2.mp4
```

```python
from h3_apple import generate

result = generate(prompt_file="scene.txt", reference_images=["portrait.jpg"],
                  duration=5, resolution="544p", aspect_ratio="9:16",
                  x2=True, output="portrait-x2.mp4")
```

## Model preparation

First X2 use prepares a separate **5.25 GB** decoder and its LICENSE/NOTICE under
`~/Models/h3-apple/x2`. Weights are pinned by revision, size and SHA256.
Invalid existing files are preserved and reported; partial downloads resume.

```sh
h3 prepare-x2 --plan
h3 prepare-x2 --reuse-dir /path/to/downloaded-x2
```

For a custom directory, prepare with `--model-dir /path/to/x2`, then generate
with `--x2-model-dir /path/to/x2` or `x2_model_dir="/path/to/x2"`.
Generation checks combined pending model downloads against the 20 GB consent
threshold before preparation. Ordinary generation does not download X2.

Records separate sampling geometry (`model_width`, `model_height`) from
delivery (`width`, `height`). They include the decoder identity and recipe.
SOL skips native video decoding and hands normalized latents and lossless
float32 audio to the isolated MLX worker.

## Quality and evidence

Start with five-second clips. Lower-resolution sampling can change composition,
motion and identity; X2 cannot recover a scene that was never sampled correctly.
Inspect small faces, action, graphics and text for softness, halos and unstable
texture. The author's separate B32 reference enhancer is not enabled by X2.

The [four-route benchmark](releases/0.7.0.md#descriptive-benchmark) reports complete
API timing and separate task/quality scores. The
[original integration record](evidence/v0.7.0-x2-integration.json) also contains
the subsequently removed 768p + X2 experiments; those are historical results.

A bounded CPU temporal copy avoids the MLX 0.32.0 large-array offset defect.
GPU decoder arithmetic remains unchanged by that copy fix. This addresses a
specific implementation bug, not every color artifact or model failure.
Device locking, cancellation, resource monitoring and full media validation
also apply to X2.

See the [weight manifest](../src/h3_apple/data/x2-model-sources.json),
[MiniMax terms](../licenses/MiniMax-H3.txt) and retained author NOTICE.
No weights or ComfyUI runtime are bundled.
