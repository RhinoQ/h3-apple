# 0.9.0 — Pika High and optional 2× super-resolution

High now makes a five-second, native 768p clip with stereo audio using **Pika H3 Flex**.
Fast and Medium move to **LightX2V's four-step v1.0 weights**. You can run VOSR 2×
on a saved clip from any of the three presets.

[![Four frames from the Pika fan film show a pink rabbit changing outfits](https://raw.githubusercontent.com/RhinoQ/h3-apple/v0.9.0/docs/media/four-looks-under-the-fan.jpg)](https://rhinoq.github.io/h3-apple/?release=0.9.0#fan-wardrobe~2x)

*Four looks under the fan* joins three Pika High shots. The preview shows the
optional 1536×2732 restoration. [Watch the 15-second film](https://rhinoq.github.io/h3-apple/?release=0.9.0#fan-wardrobe~2x) · [Get the timings, prompts, reference images and commands](https://rhinoq.github.io/h3-apple/?release=0.9.0#fan-wardrobe~2x~generation)

| Quality | Generator | Clip length | Landscape output |
| --- | --- | --- | --- |
| Fast (default) | LightX2V v1.0, 4 steps, 544p + X2 decoder | 5–15 s | 1920×1088 |
| Medium | LightX2V v1.0, 4 steps, native 768p | 5–15 s | 1366×768 |
| High | Pika H3 Flex, 6 steps, native 768p | 5 s | 1366×768 |

Portrait swaps the dimensions. Fast and Medium still support VSA (default) or SOL.
High uses Dense attention and requires 128 GiB of unified memory.

## Coming from 0.8.3

Activate your existing environment and install the release wheel. For a first installation,
follow the [installation guide](../install.md).

```sh
conda activate h3
python -m pip install --upgrade https://github.com/RhinoQ/h3-apple/releases/download/v0.9.0/h3_apple-0.9.0-py3-none-any.whl
```

**High now saves native 768p by default.** In 0.8.3 it automatically applied VOSR.
To generate at High and save both the native and restored videos in one run, add `--upscale`.

```sh
h3 generate --quality high --image reference.jpg --prompt-file scene.txt \
  --upscale --output scene-2x.mp4
```

You can also restore a saved video later with `h3 upscale --input scene.mp4`.
VOSR requires 128 GiB and a separate 6.97 GB download. Some restoration components
are licensed for noncommercial use. [Super-resolution guide](../upscale.md)

**Model setup.** Fast and Medium use new versioned model directories and reuse
compatible cached source files. If you set a custom v0.1 model path, point it
to a v1.0 bundle or a fresh directory. High prepares a separate Pika bundle.
Run `h3 prepare --quality high --plan` to see the download and disk estimate
on your Mac. [Setup and model reuse](../install.md#optional-setup) · [Advanced settings and legacy replay](../advanced.md)

The release was tested on a 40-core M5 Max with 128 GiB. The installed runtime passed
441 tests, and six scenes exercised both generation backends, native Pika High and
optional restoration. [Watch the gallery](https://rhinoq.github.io/h3-apple/?release=0.9.0) · [Validation and measured limits](../validation.md#090) · [Implementation and credits](../development.md#implementation-and-credits)
