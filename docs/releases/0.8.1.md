# 0.8.1 — Fewer choices, faster starts

Unreleased.

Generate a five-second video with an image and a prompt. Add `--upscale` for a
detailed finish: h3-apple chooses native 768p, generates the video, then applies
2× super-resolution with its audio intact. Both videos are saved.

```sh
h3 generate --image reference.jpg --prompt "A slow push-in on Picture 1. Soft ambient music."
h3 generate --image reference.jpg --prompt "A slow push-in on Picture 1. Soft ambient music." --upscale
```

- CLI and Python default to **five seconds**. Set `--duration 15` or `duration=15`
  for longer clips.
- Super-resolution checks memory, model availability and combined download
  consent before generation. Failed restoration leaves the native video ready to retry.
- `h3 upscale --input video.mp4` also accepts default X2 video, in landscape or
  portrait. Larger inputs use bounded attention memory and keep their full size.
- Upscaling chooses a fresh output path. Generation already
  does the same. Explicit output names keep their overwrite protection.
- Interactive terminals show the saved video paths. Redirected output remains
  JSON; `--json` also works in a terminal.

Super-resolution requires **128 GiB memory**, **6.97 GB** of additional models
and about **20 extra minutes per five-second 768p clip** on the tested M5 Max.
Generation and native restoration retain their 0.8.0 arithmetic. X2 restoration
adds fixed noise for the new sizes and batches attention queries to bound memory.

The complete five-second native workflow retains its
[checks, inputs and source identities](../evidence/v0.8.1-workflow.json).
