# Faster generation with X2

X2 samples at a lower resolution and doubles decoded width and height.
The current source defaults to VSA + 544p/X2, in landscape or portrait.
SOL also supports X2. [Stable 0.8.2](releases/0.8.2.md) uses SOL by default.

Use the [standard installation](install.md) with Python 3.11.
VSA and SOL use separate generation bundles and share the X2 decoder.

```sh
h3 generate --image reference.jpg \
  --prompt "A slow cinematic push-in on the scene in Picture 1. Soft ambient music."
```

Use `--mode SOL` for SOL; add `--aspect-ratio 9:16` for portrait.
For native output, use `--resolution 768p --no-x2` or `--resolution 576p --no-x2`.
In Python, set `resolution` and `x2=False`; omitting both selects 544p/X2.

## Sampling and output

| Sampling | Landscape canvas | Landscape output | Portrait output |
| --- | --- | --- | --- |
| 544p | 960 × 544 | 1920 × 1088 | 1088 × 1920 |
| 576p | 1024 × 576 | 2048 × 1152 | 1152 × 2048 |

Portrait swaps the sampling dimensions. Output retains every decoded pixel.
544p sampling requires X2; 768p sampling uses the native decoder.
Both X2 output sizes work with [VOSR super-resolution](upscale.md).

## Model preparation

First use downloads the separate **5.25 GB** decoder to `~/Models/h3-apple/x2`.

```sh
h3 prepare-x2 --plan
h3 prepare-x2 --reuse-dir /path/to/downloaded-x2
```

For another directory, prepare with `--model-dir` and generate with
`--x2-model-dir` (`x2_model_dir` in Python). Downloads resume and are checksum-verified;
invalid existing files are preserved and reported. Consent covers combined
pending generation and X2 downloads above 20 GB.

## Quality and evidence

Start with five seconds. Check motion, faces, text and geometry: lower-resolution
sampling can change the scene, and X2 cannot recover a failed action or composition.
