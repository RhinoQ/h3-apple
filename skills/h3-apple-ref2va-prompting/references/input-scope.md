# Reference roles

Separate the file, depicted subjects and intended role: identity, appearance,
style, composition or frame anchor. Incidental contents do not automatically
define cast or staging. Clarify only ambiguities that materially affect the result.

Multiple images can describe one subject; one image can contain several.
Map `<Picture N>` to input order and keep stable `<Subject N>` labels.
Update citations after selection or reordering. Similar appearance does not
erase distinct roles.

In `retention_analysis`, assign subjects and retained attributes to each shot.
Describe who is visible, their relationships and actions. Apply composition
constraints only where relevant. Keep references needed in later shots, even
when their subjects never share a frame. Do not drop requested subjects for reliability.

An identity reference need not set the opening composition. Use standalone
picture definitions for frame/storyboard anchors. Select relevant context
without importing unrelated assets. Clear scope helps expose contradictions;
it does not guarantee identity, count, motion or timing.
