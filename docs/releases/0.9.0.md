# 0.9.0 — New Ref2VA generators and optional super-resolution

Fast and Medium use LightX2V's dedicated four-step v1.0 Ref2VA weights.
Fast samples at 544p and applies its X2 decoder. Medium delivers native 768p.
Both default to VSA and also support SOL.

High generates a five-second native 768p video with stereo audio using Pika
H3 Flex's six-step Ref2VA sampler and Dense attention. High requires 128 GiB.
Landscape output is 1366×768 and portrait output is 768×1366.

```sh
h3 generate --image reference.jpg --prompt-file scene.txt --quality high --output scene.mp4
h3 upscale --input scene.mp4 --output scene-2x.mp4
```

Use `h3 upscale` on a saved Fast, Medium or High video. To generate High and
restore it in one call, add `--upscale` or use `generate(..., quality="high", upscale=True)`.
The result includes the saved native file. In 0.8.3, High applied VOSR by
default. Its original four-step Dense workflow is available with an explicit
v0.1 model directory and the [advanced settings](../advanced.md).

The four-step bundles have versioned directories and can reuse cached original
sources. Pika uses a separate 2.77 GB adapter. Run
`h3 prepare --quality high --plan` to see the download and disk requirements.
VOSR uses a separate 6.97 GB model with noncommercial components.
