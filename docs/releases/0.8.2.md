# 0.8.2 — Choose a quality, set a duration

Generate with one quality choice instead of coordinating mode, resolution,
decoder and restoration settings:

```sh
h3 generate --image reference.jpg --prompt-file scene.txt --quality medium --duration 8.5
```

| Quality | Configuration | Duration |
| --- | --- | --- |
| `fast` (default) | SOL 544p + X2 | 5–15 seconds |
| `medium` | VSA native 768p | 5–15 seconds |
| `high` | Dense native 768p + VOSR 2× | 5 seconds |

Fast and medium accept **5–15 seconds at whole 24 fps frames**, including 7 and
8.5 seconds. High is fixed at five seconds. All three support landscape or portrait
and default to five seconds. High requires
128 GiB and saves both the native and restored videos. Medium over five seconds
requires 96 GiB. [Settings and delivered dimensions](../advanced.md).

Python uses `generate(..., quality="high")`. `resolve(...)` and
`h3 resolve` expose the same choices without loading models. Existing advanced
calls, including `upscale=True`, retain their defaults. Explicit settings that
contradict a selected quality fail before setup. High and advanced Dense calls
reject durations other than five seconds instead of truncating them.

Dense uses the existing four-step VSA model bundle with full BF16 attention and
quantized projections. High can add detail but does not guarantee correct motion,
expressions or text. VOSR preserves native output and audio; its
[requirements and noncommercial terms](../upscale.md) still apply.
