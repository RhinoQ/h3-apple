# P148 original comparison media

These 16 original videos support the [P148 review page](https://rhinoq.github.io/h3-apple/previews/p148-native-x2-quality/). Each pair uses identical native generated latents and original audio. Six pairs start at 768p; two 15-second boundary pairs start at 576p. Quality assessment is pending actual review.

This data-only branch keeps original media outside the GitHub Pages site-size limit. The page pins an immutable commit and preserves file SHA256 values. No model weights, private paths, runtime source, or reviewer notes are included.
