Generation method

Four denoising steps with native video and stereo audio generation. The collection uses a fixed seed and records the first attempt, including any failures. No cloud generation API is used.

The guide publishes prompt excerpts, so the original full requests and seeds are unknown. The source videos are 720p; these local runs use 576p. Source clips of 15.083 seconds become 15-second deliveries. Runtime also differs. These are reproductions of the public inputs, not identical copies of the hosted outputs.

Image reference, first and last frame, video reference, and audio reference are tracked separately. A missing input mode is never replaced silently.

Source & attribution

The case index refers to fal’s MiniMax H3 prompting guide. This independently authored page hosts H3 Apple’s own generation results. Reference previews link directly to the publisher’s files; they are not copied into this repository. The reproduction script retrieves the source prompt on your machine and verifies the exact text used for the local run. You can display that downloaded text in each case’s prompt panel without uploading it.
