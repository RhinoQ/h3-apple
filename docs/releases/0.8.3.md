# 0.8.3 — VSA or SOL at either quality

Choose VSA or SOL for both Fast and Medium. Both now default to VSA;
add `--mode SOL` to use SOL. High keeps Dense generation and super-resolution.

| Quality | Pipeline | Duration | Backend |
| --- | --- | --- | --- |
| Fast | 544p + X2 | 5–15 seconds | VSA (default) or SOL |
| Medium | Native 768p | 5–15 seconds | VSA (default) or SOL |
| High | Dense native 768p + VOSR | 5 seconds | VSA models with Dense attention |

```sh
h3 generate --image reference.jpg --prompt-file scene.txt --quality fast
h3 generate --image reference.jpg --prompt-file scene.txt --quality medium --mode SOL
```

Python uses the same settings: `generate(..., quality="fast", mode="SOL")` or
`generate(..., quality="medium", mode="VSA")`. Fast and medium still support
5–15 seconds at whole 24 fps frames. High remains fixed at five seconds.

## Upgrading

Calls that omit `mode`, including generation without a named quality and the
`--upscale` shortcut, now use VSA. Set `--mode SOL` or `mode="SOL"` explicitly
to keep SOL. Preparation, doctor and verification also default to VSA; use the
same explicit mode throughout setup and generation.

Each backend needs its own prepared models. Compatible models are reused;
switching backends may require a download. Transfers above 20 GB require consent.

This release adds backend selection to the existing inference implementations.
